## 1. ملخص المعمارية التقنية والتصميم (Tech & Design System Architecture)

### ألوان النظام (Color Palette & Semantic Tokens)
| العنصر | الكود اللوني (HEX) | الاستخدام الدلالي |
| :--- | :--- | :--- |
| **Primary Navy** | `#1E293B` | اللون الأساسي، أشرطة العناوين، الأزرار الأساسية، بطاقات الهوية |
| **Surface Off-White** | `#F8FAFC` / `#F8F9FF` | الخلفية العامة للشاشات لضمان التباين العالي |
| **Card Container** | `#FFFFFF` | بطاقات الشقق، عناصر الإدخال، الحاويات البيضاء مع ظلال خفيفة |
| **Success Emerald** | `#10B981` | حالات تم الدفع، الحسابات المفعلة، مؤشرات النجاح |
| **Warning / Pending Amber**| `#F59E0B` / `#F97316` | الدفعات المعلقة للمراجعة، التنبيهات المؤقتة |
| **Danger / Alert Crimson** | `#EF4444` | المتأخرات عن السداد، الأعطال الطارئة والحرجة، أزرار الحذف |
| **Border / Divider** | `#E2E8F0` / `#CBDBF5` | الحدود وحواجز الأقسام |

### التايبوجرافي ونمط الخطوط (Typography)
- **خط العناوين والنصوص:** `Cairo` / `Tajawal` / `Plus Jakarta Sans`
- **الأرقام والمبالغ المالية:** أرقام إنجليزية واضحة وعريضة مع لاحقة العملة (`ج.م` أو `EGP`) لسهولة القراءة السريعة.
- **مقاييس الأركان والظلال:**
  - `Border Radius`: زوايا دائرية متناسقة `rounded-xl` (12px) إلى `rounded-2xl` (16px).
  - `Box Shadow`: ظلال ناعمة `0 1px 3px rgba(0,0,0,0.05), 0 4px 12px rgba(30,41,59,0.04)`.

## 2. جدول فهرس الشاشات والمسارات والربط البرمجي (Screen Catalog & Routing Map)

تتألف المنظومة من **35 شاشة ومساراً تفاعلياً** مقسمة في 5 مسارات رئيسية:

### المسار 1: بوابة الانضمام والتسجيل (Authentication & Onboarding)
| # | معرف الشاشة | اسم الشاشة | نوع الصلاحية | المكونات الرئيسية والأحداث |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `AUTH_LOGIN` | شاشة تسجيل الدخول | الجميع | إدخال رقم الهاتف / البريد، التحقق بـ OTP، تذكر الدخول |
| 2 | `AUTH_SIGNUP` | تسجيل حساب جديد بالإيميل | مستخدم جديد | الاسم الكامل، البريد، كلمة المرور، تحديد الصفة |

| 4 | `RESIDENT_SELECT` | التسجيل واختيار الشقة | ساكن / مشتري | كود المبنى الموحد، قائمة منسدلة بأرقام الشقق، طلب الانضمام |

## 3. مواصفات قواعد البيانات وواجهات البرمجة (API & Data Schema Models)

### نموذج الوحدة السكنية (Unit Model)
```typescript
interface Unit {
  id: string; // e.g. "unit_302"
  buildingId: string;
  unitNumber: string; // "302"
  floor: number; // 3
  areaM2: number; // 185
  orientation: 'بحري' | 'قبلي' | 'شرقي' | 'غربي';
  resident: {
    name: string;
    phone: string;
    role: 'مالك مقيم' | 'مستأجر' | 'عضو باللجنة' | 'شاغرة';
    isVerified: boolean;
  };
  financials: {
    monthlySubscription: number; // e.g. 500 EGP
    paymentStatus: 'PAID' | 'PENDING_REVIEW' | 'OVERDUE';
    unpaidMonths: number;
    totalBalanceDue: number;
  };
  inviteCode: string; // e.g. "302-INV"
}
```

### نموذج المعاملة المالية والمصروفات (Transaction / Expense Model)
```typescript
interface FinancialTransaction {
  id: string;
  buildingId: string;
  type: 'INCOME' | 'EXPENSE' | 'EMERGENCY_FUND';
  category: 'اشتراكات شهرية' | 'صيانة مصاعد' | 'كهرباء ومياه' | 'حراسة ونظافة' | 'طوارئ';
  title: string;
  amount: number;
  date: string; // ISO 8601
  status: 'COMPLETED' | 'PENDING' | 'REJECTED';
  unitId?: string; // Optional (for subscription payments)
  invoiceAttachment?: {
    fileUrl: string;
    isOfficialStamped: boolean;
    vendorName?: string;
  };
  paymentMethod: 'INSTAPAY' | 'BANK_TRANSFER' | 'CASH';
}
```

### نموذج البلاغات والأعطال (Maintenance Ticket Model)
```typescript
interface MaintenanceTicket {
  id: string; // e.g. "BLG-2024-89"
  buildingId: string;
  reporterUnitId: string;
  reporterName: string;
  scope: 'المصعد' | 'مدخل العقار' | 'إنارة السلم' | 'طلمبة المياه' | 'الجراج' | 'أخرى';
  severity: 'NORMAL' | 'MEDIUM_48H' | 'CRITICAL_EMERGENCY';
  title: string;
  description: string;
  mediaUrls: string[]; // photos / videos
  preferredInspectionTime: 'أي وقت' | 'صباحية' | 'مسائية';
  status: 'SUBMITTED' | 'IN_PROGRESS' | 'RESOLVED' | 'CLOSED';
  costChargedToTreasury?: number;
  createdAt: string;
}
```

## 4. خطة الربط وحالات الحالة (State Management & Navigation Flow)
- **شريط التنقل السفلي الثابت (Bottom Tabs):**
  - تفعيل 4 أقسام رئيسية حسب دور المستخدم:
    - **لرئيس الاتحاد:** [الرئيسية ⊞] - [الوحدات 🏢] - [المصروفات 📑] - [الإعدادات ⚙️]
    - **للساكن:** [الرئيسية ⊞] - [مجتمع العمارة 👥] - [المصروفات 📑] - [المزيد ⋯]
- **التعامل مع الروابط العميقة (Deep Links):**
  - روابط الدعوات: `ittihad://invite/{inviteCode}` تفتح مباشرة شاشة الانضمام المخصصة برقم الشقة وتملأ الحقول تلقائياً.
  - إشعارات الدفع والواتساب: فتح مباشر لنموذج سداد الاشتراك وتفاصيل الحساب البنكي.
